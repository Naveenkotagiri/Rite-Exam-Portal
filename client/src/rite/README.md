# Rite design tokens

Copied unchanged from the Rite Design System repository
(github.com/RiteProductsPlatform/Rite-Design-System, `tokens/`).
To update the look, replace these files with newer copies; `../styles.css` only references the
variables they define.

Not copied: `fonts.css` (the fonts are self-hosted from `@fontsource/poppins` and
`@fontsource/ibm-plex-mono`, imported in `main.jsx`, so exams never depend on a font CDN) and
`base.css` (its element defaults are folded into `../styles.css`).
